# 📱 Guide d'installation - SMSenvoie (Android)

> **Version actuelle de l'app : v1.3.19+66**

## 🆕 Nouveautés de la v1.3.19

- 🔐 **Connexion permanente** : vous restez connecté à votre compte **en permanence**. Fini les déconnexions qui demandaient de ressaisir email et mot de passe — même après un redémarrage du téléphone.
- 🔄 **Redémarrage automatique** : le service d'envoi SMS reprend tout seul quand le téléphone redémarre.
- 🛡️ **Anti-spam toujours actif** : délais aléatoires entre les SMS, pauses par lot et variation du texte protègent votre SIM du blocage opérateur.

💡 *L'application se met à jour automatiquement : quand une nouvelle version est disponible, une bannière s'affiche dans l'app — suivez simplement les instructions.*

---

## Étape 1 : Télécharger l'application

- Cliquez sur le lien que vous avez reçu (ou https://smsenvoie.com/app/download)
- Téléchargez le fichier **`sms-gateway.apk`**
- Le fichier sera dans vos **Téléchargements**

---

## Étape 2 : Autoriser l'installation

⚠️ **Important** : Android affichera un message de sécurité, c'est normal !

### Quand vous voyez "**Google Play Protect**" :

1. Cliquez sur **"Plus d'infos"** ou **"Détails"**
2. Cliquez sur **"Installer quand même"**
3. C'est tout ! ✅

**Pourquoi ce message ?**  
Cette application n'est pas sur le Play Store, Android affiche toujours cet avertissement par sécurité. **L'application est sûre et signée par SMSenvoie.**

---

## Étape 3 : Installer l'application

1. Ouvrez vos **Téléchargements**
2. Tapez sur **`sms-gateway.apk`**
3. Si demandé, autorisez votre navigateur/gestionnaire de fichiers à **"Installer des applications"**
4. Tapez sur **"Installer"**
5. Attendez quelques secondes ⏳
6. ✅ **Installation terminée !**

---

## Étape 4 : Permissions requises

Au premier démarrage, l'application vous guide pour accorder les permissions :

- 📱 **SMS** : pour envoyer les messages (c'est le cœur de l'app !)
- 📞 **Téléphone** : pour gérer les multi-SIM
- 🔔 **Notifications** : pour suivre la progression des envois
- 🔋 **Batterie** : pour éviter qu'Android n'arrête l'envoi en arrière-plan

**Ces permissions sont indispensables** pour que l'application fonctionne.

---

## ✅ Après installation

1. Lancez **SMSenvoie**
2. Connectez-vous avec vos identifiants (email/mot de passe) — **une seule fois** : la connexion est désormais permanente
3. Scannez le QR code depuis votre tableau de bord web (**Appareils** → Ajouter)
4. Commencez à envoyer des SMS ! 🚀

### 🔋 Conseil : optimiser l'envoi en continu

Pour que l'envoi ne soit jamais interrompu, désactivez l'optimisation de batterie pour SMSenvoie :
**Paramètres → Applications → SMSenvoie → Batterie → "Aucune restriction"** (le libellé varie selon les marques : Samsung, Xiaomi, Tecno, Infinix...).

## 🔌 Pour les développeurs : API SMSenvoie

Vous voulez connecter votre boutique e-commerce, votre CRM ou votre propre application ?
SMSenvoie propose une **API REST** : chaque utilisateur peut générer ses clés API depuis
**Dashboard → Clefs API** et envoyer des SMS depuis n'importe quel système.

- 📖 Documentation complète : **https://smsenvoie.com/docs/api**
- 🔑 Gestion des clés (création, suivi, révocation immédiate et définitive) : **Dashboard → Clefs API**

## 🆘 Problèmes d'installation ?

### "Application non installée"
➡️ **Cause** : Une ancienne version de l'app est déjà sur votre téléphone.  
➡️ **Solution** : Désinstallez l'ancienne version, puis réinstallez.

### "Installation bloquée"
➡️ **Solution** : Paramètres → Sécurité → Autoriser les **"Sources inconnues"** pour votre gestionnaire de fichiers.

### L'app demande de se reconnecter
➡️ Mettez à jour vers la **v1.3.19** ou supérieure : la connexion devient permanente.
