# 📱 Guide d'installation - SMS Gateway (Android)

## Étape 1 : Télécharger l'application

- Cliquez sur le lien que vous avez reçu
- Téléchargez le fichier **`SMS-Gateway.apk`**
- Le fichier sera dans vos **Téléchargements**

---

## Étape 2 : Autoriser l'installation

⚠️ **Important** : Android affichera un message de sécurité, c'est normal !

### Quand vous voyez "**Google Play Protect**" :

1. Cliquez sur **"Plus d'infos"** ou **"Détails"**
2. Cliquez sur **"Installer quand même"**
3. C'est tout ! ✅

**Pourquoi ce message ?**  
Cette application n'est pas sur le Play Store, Android affiche toujours cet avertissement par sécurité. **L'application est sûre et signée par SMS Gateway SaaS.**

---

## Étape 3 : Installer l'application

1. Ouvrez vos **Téléchargements**
2. Tapez sur **`SMS-Gateway.apk`**
3. Si demandé, autorisez votre navigateur/gestionnaire de fichiers à **"Installer des applications"**
4. Tapez sur **"Installer"**
5. Attendez quelques secondes ⏳
6. ✅ **Installation terminée !**

---

## Étape 4 : Permissions requises

L'application vous demandera les permissions suivantes :

- 📷 **Appareil photo** : pour scanner les QR codes de connexion
- 📱 **SMS** : pour envoyer les messages (c'est le cœur de l'app !)
- 📞 **Téléphone** : pour gérer les multi-SIM

**Ces permissions sont indispensables** pour que l'application fonctionne.

---

## 🆘 Problèmes d'installation ?

### "Application non installée"
➡️ **Cause** : Une ancienne version de l'app est déjà sur votre téléphone.  
➡️ **Solution** : Désinstallez l'ancienne version, puis réinstallez.

### "Installation bloquée"
➡️ **Solution** : Paramètres → Sécurité → Autoriser les **"Sources inconnues"** pour votre gestionnaire de fichiers.

### Autres problèmes
➡️ Contactez le support : [votre email support]

---

## ✅ Après installation

1. Lancez **SMS Gateway**
2. Connectez-vous avec vos identifiants (email/mot de passe)
3. Scannez le QR code depuis votre tableau de bord web
4. Commencez à envoyer des SMS ! 🚀
